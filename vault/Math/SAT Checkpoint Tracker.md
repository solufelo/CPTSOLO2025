## Weak-area -> drill-book map

- Arithmetic/fractions -> Kelley Basic Math chapters
- Linear equations/systems -> McMullen Algebra Essentials
- Quadratics/functions -> McMullen Master Essential Algebra
- Angles/triangles/trig -> McMullen Trig Essentials
- Word problems -> Pólya four steps, explicitly: understand / plan / execute / look back

## One-time setup (10 min)

1. Settings -> Community plugins -> turn off Restricted mode
2. Install **Excalidraw** (the tablet handwriting core)
3. Install **Templater** or use core Templates plugin -> point it at the `Templates` folder
4. Settings -> Core plugins -> enable **Daily notes** -> template: `Templates/Daily Template`, folder: `Daily`

## The three working folders

- `Daily/` — one note per day, four sections, never skip "Tomorrow's first move"
- `Math/` — one Excalidraw file per study session + the SAT Checkpoint Tracker
- `LightYears/` — devlogs, one note per phase

# LeetCode Tracker

Active recall repository of data structures and algorithms drills. Focus on understanding patterns, not memorizing.

## LeetCode MMR Goals
- target: 1-2 problems per day.
- key topics: arrays, two pointers, sliding window, binary search, trees, graphs, backtracking.

## The Strategy
- **Retrieve before reveal:** Attempt to solve on paper/tablet for 20 minutes before looking at solutions.
- **Identify the pattern:** Don't just make it pass; explain *why* the optimal approach works (Feynman technique).

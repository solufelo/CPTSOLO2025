# Obsidian + Drawing Tablet Workflow

Writing and reading, not listening. Generation effect: you retain what you PRODUCE.
Handwriting engages motor-memory circuits typing never touches. Sit in your head, pen in hand.

## Setup (one-time)

1. Install Obsidian
2. Install the **Excalidraw** community plugin — this is the core. Handwrite every math
   problem on the tablet inside a note; embed drawings next to typed reflections
3. Three folders only: `Daily`, `Math`, `LightYears`
   (Elaborate vault systems are procrastination wearing a productivity costume)

## Daily Note Template

```
## What I worked (math)
## What I built (game)
## What I learned (one paragraph, own words, book closed)
## Tomorrow's first move
```

## The Feynman Rule

After every chapter/lecture: write an explanation AS IF TEACHING IT, source closed.
Where you stall = where you don't actually know = tomorrow's first move.

## Math Session Format

- One Excalidraw file per study session
- Attempt by hand -> check book solution -> re-attempt blind if failed
- Biweekly SAT checkpoint scores logged in a single running note (the MMR tracker)

## Devlog Format (Light Years)

- One note per phase, append as you go
- What worked / what fought back / screenshot or gif
- These become the repo README and your interview stories verbatim

# Daily Protocol — The Keystone Doc

The order is the system. Times can shift; the order cannot.

## The Day

1. **Wake -> neuro calibration + calisthenics (20-25 min)**
   See NEURO-CALIBRATION.md: sprints, barefoot juggle, then pull-ups/dips (../protocols/FITNESS-SETUP.md).
   Optional: 5 min Aimbeast target switching (120cm→28cm curve map).

2. **Math block (45-60 min)**
   - 20-30 min McMullen drills (current act's drill book)
   - Remainder: Kelley / Stewart, attempt-first, by hand in Obsidian

3. **French block (20 min)**
   Vocabulaire Progressif one unit + word bank log. See FRENCH-TRACK.md.

4. **Build block (2 hrs)** — rotate by day, **learn-first**
   - You type the code. AI reviews and quizzes, does not dump full apps.
   - Mon/Wed/Fri: Light Years slices (../roadmaps/LIGHTYEARS-ROADMAP.md)
   - Tue/Thu: Priority Engine or StudyOS slices (../roadmaps/PRIORITY-ENGINE-LEARNING-PATH.md)
   - End block: CODE-REVIEW-CHECKLIST + Learning Log entry

5. **Job / LeetCode block (1.5 hrs)**
   - 45 min LeetCode / DSA drills (active recall problem solving).
   - 45 min Outbound Outreach (Loom pitches, direct DMs, tracking via SIGMA pipeline). See JOB-PIPELINE.md.

6. **Games / aim training**
   Reward only. Named intention required (../protocols/MEDIA-PROTOCOL.md).

7. **Close the day (5 min)**
   Daily note in Obsidian, four lines:
   - What I worked (math)
   - What I built (game)
   - What I learned (one paragraph, own words, book closed)
   - **Tomorrow's first move** (never skip: decision fatigue at wake-up is what keeps people in bed)
   - **Audit Commit:** run `.\scripts\audit-commit.ps1` in captainsoloHQ to save daily logs to Git.

## Total real work: ~5 hours (French adds 20 min; neuro adds 5 min)

Not a grind fantasy. Just enough to compound.

## The Dependency Chain

Loans <- job <- portfolio + pipeline <- daily blocks <- getting vertical before noon.
One chain. One keystone. Protect the morning.

## Failure Protocol

Missed a day? Zero self-punishment, zero make-up doubling. Tomorrow: calisthenics, then the
smallest possible math task (one drill page). Restart momentum, not penance.

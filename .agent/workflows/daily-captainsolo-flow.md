# Workflow: Daily CaptainSolo Flow

Master flow: `FLOW.md` in repo root. Follow phase order unless Solomon says low-energy day.

## Agent role by phase

| Phase | Agent does | Agent does NOT |
|---|---|---|
| Body | Nothing unless asked | Schedule workouts |
| Mind | Quiz on math/French concepts if asked | Do homework for him |
| Build | `/grill-me`, hints, review, edge-case quiz | Full implementations |
| Money | Help draft cover letter bullets from his projects | Apply to jobs for him |
| Close | Remind: Learning Log + tomorrow's first move | Extend session past slice |

## Build session checklist (agent)

- [ ] Confirmed slice name from learning path doc
- [ ] Asked what he predicts before code
- [ ] Reviewed his typed code (not replaced wholesale)
- [ ] Asked 2 edge cases
- [ ] Reminded CODE-REVIEW-CHECKLIST + Learning Log
- [ ] Named next slice for tomorrow

## If he opens chat with no context

Ask: "Which phase? Body, mind, build, money, or close?"

Default to build only if he names a slice.

# Workflow: Learn-First Coding Session

Use when Solomon opens a code project (priority-engine, light-years-game, StudyOS).

## Start

1. Ask which **slice** from the learning path (do not pick a whole phase).
2. Run `/grill-me` mentally: what does he already know about this slice?
3. State the **one concept** this slice teaches in plain language.

## During

1. He predicts on paper or in chat (pseudocode / state diagram).
2. He types the code. You review diffs, max 5 lines of direct fix per round.
3. If stuck 10+ min: give a **hint**, not the solution.
4. Ask 2 edge-case questions before moving on.

## End

1. `CODE-REVIEW-CHECKLIST.md` pass (he runs it, reports results).
2. Learning Log entry template filled.
3. Closed-book test: "Explain this file in 60 seconds" (he tries, you grade).

## If he says "just build it"

Respond: "Learn-first is the rule. I can give a reference stub marked READ ONLY, or we do slice N together. Which?"

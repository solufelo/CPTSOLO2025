## Master Execution Stack (one page)

What you actually run day to day. Basics strikethrough mentally.

### Morning (Act 0 + Neuro)
1. Max effort sprints (not slow cardio)
2. Barefoot dead-weight juggle in front of bed
3. Contrast shower OR percussion therapy if sore
4. Pull-ups / parallette dips (../protocols/FITNESS-SETUP.md)
5. Optional: 5 min Aimbeast target switching (120→28cm map)

### Cognition block
1. Math: Kelley/McMullen attempt-first (../tracks/REDEMPTION-ARC.md)
2. French: Vocabulaire Progressif unit + Word Bank
3. Comprehensible input OR exchange (not apps-only)

### Build block (rotate)
| Day | Track | Better-alt focus |
|---|---|---|
| Mon | WASM shooter | Raylib → Emscripten, open-source engine folder |
| Tue | StudyOS | ASP.NET Core API + React, case study doc |
| Wed | WASM shooter | Public GitHub architecture README |
| Thu | StudyOS / agency | CaptainSolo portfolio page, Blazor eval |
| Fri | WASM or Godot aim | C++ module trainer if aim week |

### Aim block (reward, intentional)
1. Aimbeast: dynamic click varied distance → 360 tracking
2. Valorant Op DM OR CS2 AWP DM (not mindless DM)
3. Live: Apex hot drops / R5 strafing bots only after drills

### Fuel & recovery
1. Meal prep protein (not default takeout)
2. Cervical pillow / spinal alignment sleep
3. Foam roller + peanut ball after long aim sessions
